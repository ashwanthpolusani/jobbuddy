# JobBuddy WebApp

The responsive, high-performance web frontend for **JobBuddy** — an entry-level and early-career tech job discovery platform.

Designed to work out-of-the-box with **[jobbuddy-scraper](https://github.com/ashwanthpolusani/jobbuddy-scraper)** via MongoDB Atlas.

---

## ⚡ Two Ways to Use This WebApp

### Choice 1: Instant Plug & Play on Our Hosted Site (Zero Setup)
You do **not** need to clone or deploy this frontend to view your scraped jobs! You can use our live production site:

1. Open **[https://buddyjob.netlify.app/](https://buddyjob.netlify.app/)**
2. Click the **"⚙️ Connect DB"** button in the header navigation.
3. Paste your **Read-Only MongoDB Connection String**:
   ```
   mongodb+srv://webapp_reader:<PASSWORD>@jobbuddy-cluster.xxxxx.mongodb.net/job_aggregator?retryWrites=true&w=majority
   ```
4. Click **Connect Database**.
5. **What happens instantly:**
   - Status badge switches to **🟢 Custom DB**.
   - Your private scraped jobs load directly into the feed.
   - Category tabs automatically adapt to your configured tracks (e.g., Software Engineering, Data/AI, Systems Analyst).
   - Your target cities appear as 1-click filter pills.
   - The connection string is saved strictly in your local browser `localStorage` and sent over an encrypted HTTPS header (`x-mongo-uri`). It is never stored or logged on our server.

> **Security Reminder:** Always use a MongoDB user with the **read-only** role (`webapp_reader`) when connecting your database. Never use administrative or write-access credentials in a web browser.

### Choice 2: Self-Host / Deploy Your Own Copy

If you want your own branded site, custom domain, or custom styling:

#### 1. Fork & Clone
```bash
git clone https://github.com/<your-username>/scrapperbuddy.git
cd scrapperbuddy/webapp
```

#### 2. Install Dependencies
```bash
npm install
```

#### 3. Configure Local Environment
Create a `.env` file in `webapp/`:
```env
MONGODB_URI="mongodb+srv://webapp_reader:<PASSWORD>@jobbuddy-cluster.xxxxx.mongodb.net/job_aggregator?retryWrites=true&w=majority"
PORT=3000
```

#### 4. Run Development Server
```bash
npm start
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

#### 5. Deploy to Netlify
1. Connect your forked GitHub repository to [Netlify](https://www.netlify.com/).
2. Under **Site configuration > Environment variables**, add:
   - `MONGODB_URI` = `<Your Read-Only Connection String>`
3. Deploy! Netlify automatically reads `netlify.toml`, launches the serverless functions in `netlify/functions/`, and deploys edge rate-limiting.

## Architecture & Data Flow

- **Frontend Core:** Vanilla HTML5, modern CSS3, and ES6+ JavaScript (0 dependencies, 100/100 Lighthouse performance, ultra-fast TTFB).
- **Dynamic Category & Location Engine:** `netlify/functions/getJobs.js` reads active metadata from the MongoDB `meta` collection generated by the scraper. If no metadata exists, it automatically falls back to `collection.distinct("category")` so no job is ever hidden.
- **Serverless API Layer:** Netlify serverless functions (`getJobs.js`, `getSiteStats.js`) query MongoDB Atlas with a warm connection pool (`cachedClients` map).
- **Edge Layer:** Netlify Edge Function rate-limiter (`netlify/edge-functions/rate-limiter.ts`) protects against traffic spikes.
- **Companion Scraper:** Works seamlessly with the autonomous [jobbuddy-scraper](https://github.com/ashwanthpolusani/jobbuddy-scraper) engine.
