How to Connect Your Scraper to Rolenaut

A comprehensive guide on running the backend job scraper, configuring a free MongoDB Atlas cluster, and connecting your read-only database URL to the Rolenaut frontend.

📖 Setup & Architecture Guide ⚡ 3-Step Walkthrough 🔒 Zero Admin Exposure

1. Understanding the Rolenaut Architecture

Rolenaut is an autonomous, candidate-owned tech career discovery platform. It decouples the web frontend from the scraping engine so that every user has full ownership over what jobs they track, which companies they scrape, and how often they refresh their feed.

The Decoupled Architecture

1. Backend Scraper (scrapperbuddy): Runs locally on your machine or on a scheduled cloud runner (e.g., GitHub Actions, Railway). It collects active requisitions directly from Workday, Lever, and Greenhouse systems and saves them to your MongoDB database.

2. MongoDB Atlas Database: Stores your scraped jobs collection (job_aggregator.jobs). You control who has access with a read-only user.

3. Rolenaut WebApp: Reads your jobs via your secure, read-only MongoDB URL. Netlify Database stores your user profile so your preferences sync anywhere you sign in.

2. Three-Step Setup Process

1 Run Your Companion Backend Scraper

Clone the open-source scraper repository and install its dependencies in Python 3.10+:

# 1. Clone the companion scraper repository
git clone https://github.com/ashwanth-1729/scrapperbuddy.git
cd scrapperbuddy

# 2. Set up virtual environment and dependencies
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
pip install -r requirements.txt

# 3. Configure target roles and cities in scraper_config.yaml
# 4. Run the scraper to populate your MongoDB cluster
python main.py

The scraper queries company ATS job boards directly, deduplicates postings, classifies experience requirements, and writes normalized documents to your MongoDB jobs collection.

2 Configure MongoDB Atlas & Read-Only Connection (Step-by-Step)

Set up a free cloud database on MongoDB Atlas (M0 Free Tier is 100% free forever with no credit card required):

2A. Create Project & Free M0 Cluster

  1. Log into MongoDB Atlas, open the Projects dropdown on the top-left, and click New Project (name it Rolenaut Workspace).
  2. Click Create Deployment (or Build a Database).
  3. Under tier options, select M0 (Free).
  4. Choose your preferred Cloud Provider (AWS recommended, or GCP/Azure) and choose a Region geographically close to your location (e.g., ap-south-1 Mumbai or us-east-1 Virginia).
  5. Keep the default cluster name (Cluster0) and click Create Deployment.

2B. Configure Network Access (Allow Serverless Connection)

  1. In the left sidebar under Security, click Network Access.
  2. Click Add IP Address.
  3. Click the Allow Access from Anywhere button (this automatically fills 0.0.0.0/0).
  4. Click Confirm. (Required so Netlify serverless functions and scraper cloud runners can connect without IP restrictions).

2C. Create Database Users (Roles & Security)

  1. In the left sidebar under Security, click Database Access → Add New Database User.
  2. Select Password authentication.
  3. Create your frontend reader user (e.g. username webapp_reader) and enter a secure password.
  4. Under Database User Privileges, assign Built-in Role: readAnyDatabase (or grant read specifically on job_aggregator). This ensures the frontend cannot delete or alter your jobs.
  5. Click Add User. (Tip: For your scraper runner, create a separate user with readWriteAnyDatabase).

2D. Retrieve and Format Your Connection String

  1. In the left sidebar, click Database to return to your clusters view.
  2. Click the Connect button next to Cluster0.
  3. Under connection methods, select Drivers → Node.js.
  4. Atlas displays your base connection template: mongodb+srv://<db_username>:<db_password>@cluster0.xxxxx.mongodb.net/
  5. Replace <db_username> with your reader username (e.g., webapp_reader).
  6. Replace <db_password> with your database user password (e.g., YourSecurePassword123).
  7. (Optional) You can paste the raw connection string directly into Rolenaut — the platform automatically targets the job_aggregator database for you.

Your Final Connection String will look like this:

mongodb+srv://webapp_reader:<db_password>@cluster0.xxxxx.mongodb.net/job_aggregator?retryWrites=true&w=majority
3 Login and Add MongoDB URL on Rolenaut Frontend

Once you have your webapp_reader connection string, plug it into the Rolenaut frontend:

  1. Click Sign In / Workspace in the top-right header of Rolenaut (authenticate via Netlify email magic link).
  2. Click your account pill in the header to open the Account & Workspace modal.
  3. Paste your read-only connection string into the MongoDB Read-Only URI field.
  4. Click Save to Netlify Profile.

Your connection string is stored securely in your private Netlify cloud PostgreSQL profile. Every time you log in from any phone, laptop, or browser, your personal feed will load automatically.

🔒 Security Best Practices

1. Always use a Read-Only User: Never use your cluster admin or primary scraper writer credentials in the web frontend. Creating a dedicated webapp_reader user ensures the browser can never write, delete, or alter any documents.

2. Encrypted Transmission: Your connection string is never included in URL parameters or browser history. It is sent exclusively via encrypted HTTPS request headers.

3. 1-Click Disconnect: You can disconnect your database anytime by clicking Disconnect Database in the Account modal.

3. Frequently Asked Questions

What if my scraper uses custom job categories?

Rolenaut's frontend dynamically inspects the distinct categories present in your MongoDB collection. If your scraper discovers devops_cloud or product_design, matching category pills will automatically generate on your dashboard.

Can I use Rolenaut with my existing scraper instead of rolenaut-engine?

Yes! Rolenaut requires only standard job document fields in your MongoDB jobs collection: title, company_name, location, link, link_type (direct_apply or filtered_list), and optional category.
