How to Connect Your Scraper to JobBuddy

A comprehensive guide on running the backend job scraper, configuring a free MongoDB Atlas cluster, and connecting your read-only database URL to the JobBuddy frontend.

📖 Setup & Architecture Guide ⚡ 3-Step Walkthrough 🔒 Zero Admin Exposure

1. Understanding the JobBuddy Architecture

JobBuddy is an open, candidate-owned tech career discovery platform. It decouples the web frontend from the scraping engine so that every user has full ownership over what jobs they track, which companies they scrape, and how often they refresh their feed.

The Decoupled Architecture

1. Backend Scraper (jobbuddy-scraper): Runs locally on your machine or on a scheduled cloud runner (e.g., GitHub Actions, Railway). It collects active requisitions directly from Workday, Lever, and Greenhouse systems and saves them to your MongoDB database.

2. MongoDB Atlas Database: Stores your scraped jobs collection (job_aggregator.jobs). You control who has access with a read-only user.

3. JobBuddy WebApp: Reads your jobs via your secure, read-only MongoDB URL. Netlify Database stores your user profile so your preferences sync anywhere you sign in.

2. Three-Step Setup Process

1 Run Your Companion Backend Scraper

Clone the open-source scraper repository and install its dependencies in Python 3.10+:

# 1. Clone the companion scraper repository
git clone https://github.com/ashwanthpolusani/jobbuddy-scraper.git
cd jobbuddy-scraper

# 2. Set up virtual environment and dependencies
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
pip install -r requirements.txt

# 3. Configure target roles and cities in scraper_config.yaml
# 4. Run the scraper to populate your MongoDB cluster
python main.py

The scraper queries company ATS job boards directly, deduplicates postings, classifies experience requirements, and writes normalized documents to your MongoDB jobs collection.

2 Configure MongoDB Atlas & Read-Only User

Create a free cluster on MongoDB Atlas (M0 tier is 100% free forever):

  1. In MongoDB Atlas, navigate to Database Access → Add New Database User.
  2. Set authentication method to Password and enter a username, such as webapp_reader.
  3. Under Database User Privileges, assign the Built-in Role: readAnyDatabase (or grant read access specifically on the job_aggregator database).
  4. In Network Access, ensure your cluster allows connections from serverless functions by adding IP 0.0.0.0/0 (Allow Access from Anywhere).
  5. Click Connect → Drivers (Node.js) to copy your connection string:
mongodb+srv://webapp_reader:<PASSWORD>@your-cluster.xxxxx.mongodb.net/job_aggregator?retryWrites=true&w=majority
3 Login and Add MongoDB URL on JobBuddy Frontend

Once you have your webapp_reader connection string, plug it into the JobBuddy frontend:

  1. Click Sign In / Workspace in the top-right header of JobBuddy (authenticate via Netlify email magic link).
  2. Click your account pill in the header to open the Account & Workspace modal.
  3. Paste your read-only connection string into the MongoDB Read-Only URI field.
  4. Click Save to Netlify Profile.

Your connection string is stored securely in your private Netlify cloud PostgreSQL profile. Every time you log in from any phone, laptop, or browser, your personal feed will load automatically.

🔒 Security Best Practices

1. Always use a Read-Only User: Never use your cluster admin or primary scraper writer credentials in the web frontend. Creating a dedicated webapp_reader user ensures the browser can never write, delete, or alter any documents.

2. Encrypted Transmission: Your connection string is never included in URL parameters or browser history. It is sent exclusively via encrypted HTTPS request headers.

3. 1-Click Disconnect: You can disconnect your database or switch back to demo mode anytime by clicking Disconnect Database in the Account modal.

3. Frequently Asked Questions

What if my scraper uses custom job categories?

JobBuddy's frontend dynamically inspects the distinct categories present in your MongoDB collection. If your scraper discovers devops_cloud or product_design, matching category pills will automatically generate on your dashboard.

Can I use JobBuddy with my existing scraper instead of jobbuddy-scraper?

Yes! JobBuddy requires only standard job document fields in your MongoDB jobs collection: title, company_name, location, link, link_type (direct_apply or filtered_list), and optional category.
